

# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, assign categories, search for notes and delete notes. Notes are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work or Study categories.
- Validate empty notes and notes longer than 200 characters.
- Display the date and time each note was created.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the number of saved notes.
- Save notes using localStorage.
- Responsive layout for smaller screens.

## How to Run Locally

1. Download or clone this repository.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start adding and searching your notes.
